# Twin Simulator

A digital twin simulator application built with Angular. This project allows users to simulate and visualize digital twins for various assemblies and projects.

## Features

- Dashboard for overview
- 3D Viewer for models
- Simulation engine
- Project management

## Installation

1. Clone the repository:
   ```
   git clone https://github.com/ajaysbsic/twin-simulator.git
   cd twin-simulator
   ```

2. Install dependencies:
   ```
   npm install
   ```

## Usage

To start the development server:
```
npm start
```

The application will be available at `http://localhost:4200`.

To run tests:
```
npm test
```

To build for production:
```
npm run build
```

## Project Structure

- `src/app/dashboard/` - Main dashboard component
- `src/app/viewer/` - 3D viewer component
- `src/app/engine/` - Simulation engine
- `src/app/models/` - Data models
- `src/app/services/` - Services for data management
